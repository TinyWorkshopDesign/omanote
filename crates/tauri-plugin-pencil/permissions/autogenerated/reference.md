## Default Permission

Everything the sketch canvas uses.

#### This default permission set includes the following:

- `allow-open`
- `allow-set-frame`
- `allow-set-tool`
- `allow-set-enabled`
- `allow-undo`
- `allow-redo`
- `allow-clear`
- `allow-export`
- `allow-close`
- `allow-register-listener`
- `allow-remove-listener`
